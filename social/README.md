# Social images

Rendered carousels for TikTok (1080×1920) and Instagram (1080×1350).

- Scripts (text, captions, sources): `docs/social/`, generated by `scripts/social.py`, which also writes `docs/social/carousels.json`.
- Renderer: `social/render/render.py` (Python 3 + Pillow). Shared visual system: `social/render/greece_style.py`. Fonts: DejaVu (licence in `social/render/fonts/`).
- Output: `social/out/<slug>/tiktok-NN.jpg`, `instagram-NN.jpg`, `contact-sheet.jpg`, and `social/out/index.md` with every caption.

```bash
python3 scripts/social.py
python3 social/render/render.py            # all 20
python3 social/render/render.py 04-seven-percent-numbers   # just one
```

Rules built into the renderer: every photo must exist in `src/static/img/`, and a slide that names a place may not use a photo whose file name names a different place. On TikTok images, text stays at least 330px above the bottom edge, clear of the app's buttons and caption.
